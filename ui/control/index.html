Providers

          

            Paste an API key → the model list fills with the provider's live models → pick one → Use.
            Each provider holds its own key / OAuth / base URL; a credential badge shows the mode
            (apikey oauth, ★ = preferred, × removes).
            OAuth login runs right here for Claude/Anthropic (approve in the opened tab, paste the code);
            other providers show the CLI command.
            Configured providers sort to the top; changes apply to new agent runs.

Missions —

          

            Autonomous engineering: give XClaw a high-level objective and a repository.
            It builds context, plans, implements in an isolated shadow workspace,
            runs the project's own tests, repairs failures, and only offers a Merge
            once verification passed — your repo is untouched until then. Rollback
            discards the workspace.

Lifecycle hooks —

          

            Custom functions at key points in every agent run: rewrite the incoming message,
            gate or rewrite tool calls (pre_tool_use decisions feed the approval
            system), transform outputs, or veto completion (on_stop).
            Command hooks run as separate processes — JSON on stdin, JSON verdict on
            stdout, exit 2 blocks. Full guide: docs/HOOKS.md.
