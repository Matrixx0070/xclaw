Providers

          

            Paste an API key → the model list fills with the provider's live models → pick one → Use.
            Each provider holds its own key / OAuth / base URL; a credential badge shows the mode
            (apikey oauth, ★ = preferred, × removes).
            OAuth logins are CLI-side: xclaw providers oauth --provider <id>.
            Configured providers sort to the top; changes apply to new agent runs.

Channels

          

            Enable a messaging channel and set its credentials (bot tokens, IMAP/SMTP) — the same
            as xclaw channels …. Secrets are stored in the (mode 600) config, never
            shown back. Changes apply on the next gateway start / channel restart.
